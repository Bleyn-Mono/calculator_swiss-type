# Логические операции

## 1 Core Concepts

### 1.1 Булева алгебра

Логические операторы работают с булевыми значениями (`True` и `False`) и возвращают булев результат.

### 1.2 Приоритет (Порядок выполнения)

У логических операторов есть своя иерархия. Сначала выполняется `not`, затем `and`, и в последнюю очередь `or`.

### 1.3 Ленивые вычисления (Short-circuit evaluation)
Python оптимизирует вычисления. Ленивые вычисления гарантируют, что если A в A and B ложно, то B не вычисляется вовсе. Это позволяет безопасно проверять существование объекта и его атрибут в одной строке: `if obj and obj.value > 0`.

### 1.4 В `and` 

Если первое условие `False`, второе даже не проверяется (результат уже точно `False`).

### 1.5 В `or`

Если первое условие `True`, второе не проверяется (результат уже точно `True`).

### 1.5 Truthiness (Истинность типов)

В логическом контексте Python считает "ложными" (`False`): `0`, `0.0`, `""` (пустая строка), `[]` (пустой список), `{}` (пустой словарь) и `None`. Все остальное считается истинным.

## 2. Syntax

### 2.1 Оператор `and` (Логическое И)

Возвращает `True`, только если **оба** операнда истинны.

```python
# Условие: число должно быть больше 0 И меньше 100
x = 25
if x > 0 and x < 100:
    print("Число в диапазоне")
```

### 2.2 Оператор `or` (Логическое ИЛИ)

Возвращает `True`, если **хотя бы один** из операндов истинен.

```python
# Условие: доступ разрешен, если есть ключ ИЛИ вы администратор
if has_key or is_admin:
    print("Доступ открыт")
```

### 2.3 Оператор `not` (Логическое НЕ)

Инвертирует значение: превращает `True` в `False` и наоборот.

```python
is_locked = False
if not is_locked:
    print("Дверь открыта")
```

### 2.4 Комбинирование со скобками

Скобки используются для изменения приоритета, чтобы код читали однозначно.

```python
# Сначала проверим условия в скобках, затем результат объединим через and
if (is_weekend or is_holiday) and not is_working_day:
    print("Можно отдыхать")
```

## 3. Best Practices

### 3.1 Избегайте двойного отрицания

Код `if not not x:` или `if not x == False:` избыточен. Пишите просто `if x:`.

### 3.2 Используйте скобки для ясности

Даже если вы помните приоритет операторов, скобки помогают другим людям быстрее понять логику.

```python
# Плохо: трудно понять без раздумий
if a or b and c != d:
    pass
# Хорошо: логика очевидна
if a or (b and (c != d)):
    pass
```

### 3.3 Упрощение цепочек сравнения

В Python можно писать математические диапазоны напрямую — это эффективнее и читаемее, чем использование `and`.

```python
# Вместо: if x > 0 and x < 10:
if 0 < x < 10:
    print("x находится между 0 и 10")
```

### 3.4 Плоское лучше вложенного

Как мы обсуждали ранее, используйте `and` для объединения условий вместо того, чтобы плодить вложенные `if`.

## 4. Error Handling

### 4.1 TypeError при работе с None

Частая ошибка — забыть проверить объект на `None` перед использованием его в логике, если он может быть пустым.

```python
user_input = None

# Ошибка: если попытаться сравнить None с числом
# if user_input > 0: ...

# Правильно: сначала проверяем на существование (ленивое вычисление спасет от ошибки)
if user_input is not None and user_input > 0:
    print("Данные корректны")
```

### 4.2 Ошибки приоритета `not`

Оператор `not` имеет очень высокий приоритет. Это часто ведет к логическим ошибкам.

```python
x = 10
y = 20
# Выражение прочитается как (not x) == y -> False == 20 -> False
if not x == y: 
    print("Это сработает, но логика может быть запутанной")

# Лучше использовать оператор неравенства напрямую:
if x != y:
    print("Числа не равны")
```

### 4.3 Пустые коллекции как False

Помните, что `if my_list:` вернет `False`, если список пуст. Это удобно, но может запутать, если вы ожидаете, что переменная вообще не существует (NameError).
