# Целые числа int()

## 1 Core Concepts

Определение: Тип данных `int` (integer) представляет собой положительные или отрицательные целые числа любой длины без дробной части.

### 1.1 Произвольная точность

В Python целые числа не имеют фиксированного размера (в отличие от других языков). Они ограничены только объемом доступной оперативной памяти вашего устройства.

### 1.2 Представление в памяти

Каждое число — это объект. Чем больше число, тем больше байтов оно занимает в памяти. 

### 1.3 Иммутабельность

Числа являются неизменяемым типом данных. При любой операции (например, x + 1) создается новый объект в памяти, а не изменяется старый.

## 2 Syntax

### 2.1 Инициализация

```Python
# Прямое присваивание
count = 10 
negative_val = -500

# Использование конструктора int()
x = int(10.5)      # Превратит float в 10 (отсечение дробной части)
y = int("100")     # Превратит строку в число 100
```

### 2.2 Системы счисления

Python позволяет записывать числа в разных системах:

```Python
binary = 0b1010    # Двоичная (10)
octal = 0o12       # Восьмеричная (10)
hexadecimal = 0xA  # Шестнадцатеричная (10)
```

### 2.3 Читаемость больших чисел 

Используйте нижнее подчеркивание для разделения разрядов (Python его игнорирует):

```Python
large_num = 1_000_000_000  # Читается легче, чем 1000000000
```

## 3 Best Practices

### 3.1 Целочисленное деление

Если вам нужен результат без остатка (например, индекс в списке), всегда используйте оператор // вместо /.

### 3.2 Имена переменных

Для счетчиков используйте говорящие имена вроде index, counter, total_items, избегая одиночных букв i, j (кроме коротких циклов).

### 3.3 Константы

Глобальные целочисленные константы пишите в UPPER_CASE.

### 3.4 Сравнение

Всегда используйте операторы сравнения (==, !=, <, >), но помните, что `is` проверяет идентичность объектов в памяти, что для чисел работает специфично из-за кэширования малых чисел (от -5 до 256).

## 4 Error Handling

### 4.1 ValueError

Возникает при попытке преобразовать строку, которая не является числом.

```Python
# Ошибка: ValueError: invalid literal for int() with base 10: 'abc'
try:
    value = int("abc")
except ValueError:
    print("Ошибка: Введенные данные не являются целым числом")
```

### 4.2 TypeError

Возникает при попытке совершить математическую операцию между `int` и несовместимым типом (например, `str`).

```Python
# Ошибка: TypeError: unsupported operand type(s) for +: 'int' and 'str'
try:
    result = 10 + "5"
except TypeError:
    print("Ошибка: Нельзя складывать число и текст напрямую")
```

### 4.3 ZeroDivisionError

Возникает при попытке деления на ноль (включая целочисленное деление и остаток).

Python
try:
    result = 10 // 0
except ZeroDivisionError:
    print("Ошибка: Деление на ноль недопустимо")
