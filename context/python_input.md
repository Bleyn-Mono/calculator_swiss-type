# 1. ввод/вывод данных

## 1. Core Concepts

Ввод данных: Передача информации от пользователя (через клавиатуру) в оперативную память программы. В Python это всегда возвращает объект типа `str` (строка).
Вывод данных: Отображение информации из памяти программы на устройстве вывода (мониторе).
Потоки: Стандартный ввод (`stdin`) и стандартный вывод (`stdout`) являются основными каналами взаимодействия консольного приложения.

## 2. Syntax

### 2.1 Базовый синтаксис

```python
data = input("Подсказка для пользователя: ")
```

### 2.2 Ввод с немедленным преобразованием типа

```python
#преобразование к целому числу
age = int(input("Введите возраст: "))
```

```python
#преобразование к числу с плавающей точкой
price = float(input("Введите цену: "))
```

### 2.3 Базовый вывод

```python
print("Текст", variable)
```

### 2.4 Использование f-строк (современный стандарт)

```python
name = "Admin"
print(f"Пользователь: {name}")
```

## 3. Best Practices

Использование f-строк: Всегда отдавайте приоритет `f"{var}"` перед склеиванием строк через + или перечислением через запятую. Это быстрее и читаемее.
Явные подсказки: В функции `input()` всегда указывайте понятный текст, чтобы пользователь знал, какого формата данные от него ожидаются.
Очистка данных: Используйте метод `.strip()` при вводе строк, чтобы избежать случайных пробелов в начале или конце:

```python
city = input("Город: ").strip()
```

Типизация: Если данные используются в расчетах, приводите их к `int` или `float` немедленно при вводе.

## 4. Error Handling

Ошибка типа `ValueError`: Возникает при попытке преобразовать некорректную строку в число (например, `int("abc")`), при обработке таких случаев используйте `try-except`.

```python
try:
    value = int(input("Введите число: "))
except ValueError:
    print("Ошибка: введено не число!")
```

Пустой ввод: Если пользователь просто нажмет Enter, `input()` вернет пустую строку "". Это нужно проверять перед обработкой:

```python
user_input = input("Введите данные: ")
if not user_input:
    print("Вы ничего не ввели")
```

Прерывание ввода: При нажатии Ctrl+C во время выполнения `input()` возникает исключение `KeyboardInterrupt`.

## 5 Дополнительные параметры sep() end() относящиеся ввод/вывод данных

### 5.1 Core Concepts

Параметр `sep` (separator): Определяет строку, которая будет вставлена между несколькими аргументами внутри одной функции `print()`. По умолчанию равен пробелу `" "`.
Параметр `end` (end of line): Определяет строку, которая выводится в самом конце работы функции `print()`. По умолчанию равен символу переноса строки `"\n"`.
Именованные аргументы: Эти параметры являются «keyword-only» аргументами, то есть они всегда должны указываться в конце списка вывода и иметь формат имя_параметра=значение.

### 5.2 Syntax

#### 5.2.1 Использование `sep`, по умолчанию `sep=" "`

```python
print("2026", "04", "26")
#Вывод: 2026 04 26
```

#### 5.2.2 Изменение разделителя

```python
print("2026", "04", "26", sep="-")
#Вывод: 2026-04-26 
```

```python
print("apple", "banana", "cherry", sep=", ")
#Вывод: apple, banana, cherry
```

#### 5.2.3 Использование `end`, по умолчанию (end="\n")

```python
print("Строка 1")
#Выведет: Строка 1
```

#### 5.2.4 Отмена или изменение переноса строки

```python
print("Загрузка...", end=" ")
print("Готово!") 
# Вывод: Загрузка... Готово! (в одну строку)
```

#### 5.2.5 Использование спецсимволов

```python
print("Завершение", end="!!!\n")
print("Следующая строка")

# Результат в консоли:
# Завершение!!!
# Следующая строка
```

#### 5.2.6 Комбинирование параметров

```python
print("Лог", "Ошибка", "404", sep=" | ", end=" [ЗАВЕРШЕНО]\n")
# Вывод: Лог | Ошибка | 404 [ЗАВЕРШЕНО]
```

### 5.3 Best Practices

Форматирование путей и дат: Используйте sep для быстрой сборки строк из элементов, например, путей файлов `sep="/"` или дат `sep="."`.
Индикаторы прогресса: Применяйте `end=""` или `end=" "` в циклах, чтобы выводить статус выполнения в одну строку, не загромождая консоль.
Читаемость: Если комбинация `sep` и многих аргументов становится слишком сложной, замените её на f-строку — это сделает код более наглядным.
CSV-стиль: Используйте `sep=";"` или `sep=","` при быстром выводе данных для последующего копирования в таблицы.

### 5.4 Error Handling

Ошибка типа `TypeError`: Параметры `sep` и `end` принимают только строки. Передача `None` или числа приведет к ошибке:

```python
print("X", "Y", sep=123)
#Ошибка: TypeError: sep must be None or a string
```

Порядок аргументов: Эти параметры должны всегда идти после всех выводимых значений. Если поставить их в начало или середину, Python выдаст `SyntaxError`.
Передача нескольких значений: Нельзя передать несколько значений в один параметр `sep` или `end`. Каждому параметру соответствует только одна строка.
