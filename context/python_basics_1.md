
# Переменные

## 1 Core Concepts

Переменная как ссылка: В Python переменная — это не «коробка», в которой лежит значение, а именованный ярлык (ссылка), указывающий на объект в памяти.
Динамическая типизация: Тип данных связан с самим объектом, а не с именем переменной. Одну и ту же переменную можно переназначить на объекты разных типов в ходе выполнения программы.
Управление памятью: Когда на объект перестает указывать хотя бы одна переменная, он автоматически удаляется из памяти «сборщиком мусора» (Garbage Collector).

## 2 Syntax

### 2.1 Cинтаксис: имя = значение

```python
count = 10          # Объект типа int
user_name = "Ivan"  # Объект типа str
```

### 2.2 Несколько переменных — разные значения

```python
x, y, z = 1, 2, 3
```

### 2.3 Несколько переменных — одно значение

```python
a = b = c = 0
```

### 2.4 Правила именования (Идентификаторы)

Можно использовать латинские буквы (a-z, A-Z), цифры и символ подчеркивания _.
Имя не может начинаться с цифры.
Регистр имеет значение: Value, value и VALUE — это три разные переменные.
Нельзя использовать ключевые слова Python (например, if, while, import).

## 3 Best Practices

Стиль PEP 8: Для имен переменных используйте формат snake_case (слова маленькими буквами через подчеркивание): user_balance, total_price.
Осмысленные имена: Избегайте коротких имен вроде a, b, c. Имя должно описывать суть данных: is_connected, max_attempts.
Константы: Для значений, которые не должны меняться, используйте UPPER_CASE: PI = 3.14159, DATABASE_URL = "localhost".
Булевы переменные: Имена логических переменных лучше начинать с префиксов is_, has_ или can_: is_valid, has_permission.

## 4 Error Handling

Ошибка имени (NameError): Возникает при попытке использовать переменную, которой еще не было присвоено значение или в имени которой допущена опечатка.

```python
print(total_sum)  # Ошибка: NameError: name 'total_sum' is not defined
```

Переопределение встроенных имен: Если назвать переменную list или int, вы потеряете доступ к одноименным встроенным функциям. Это не вызовет мгновенную ошибку, но приведет к сбою в логике позже.
Типовая безопасность: Несмотря на динамическую типизацию, попытка выполнить операцию с несовместимыми типами (например, сложение числа из одной переменной и строки из другой) вызовет TypeError.

```python
x = 10
y = '5'
print(x + y)  # Ошибка: TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

# Преобразование строки к целому числу

## 1 Core Concepts

Приведение типов (Type Casting): Процесс интерпретации строковых символов как числового значения.
Основание системы счисления: По умолчанию int() ожидает десятичное число, но может работать с любой системой от 2 до 36.
Требования к строке: Строка должна содержать только цифры, допустимы ведущие или завершающие пробелы и знак числа (+ или -). Наличие любых других символов (букв, спецсимволов, знаков пунктуации) делает преобразование невозможным.

## 2 Syntax

### 2.1 Синтаксис: int(строка)

```python
# Считывание с клавиатуры
number = int("42")
print(number + 8)  # Выведет: 50
```

### 2.2 Результат input() всегда строка, поэтому преобразование обязательно

```
# Преобразование с указанием системы счисления
user_age = int(input("Ваш возраст: "))
```

### 2.3 Синтаксис: int(строка, основание)

```
binary_val = int("1010", 2)  # Двоичная (результат: 10)
hex_val = int("FF", 16)      # Шестнадцатеричная (результат: 255)
```

## 3 Best Practices

Очистка строки: Всегда используйте `.strip()`, если данные приходят из ненадежных источников, чтобы исключить ошибки из-за случайных пробелов или знаков переноса строки.
Предварительная проверка: Если вы хотите избежать исключений, можно использовать метод `.isdigit()` (проверяет, состоит ли строка только из цифр), но помните, что он вернет `False` для отрицательных чисел из-за знака -.
Цепочка преобразований: Если строка содержит число с плавающей точкой (например, "10.5"), прямой вызов `int()` вызовет ошибку. Сначала приведите к float, а затем к 

```
int:value = int(float("10.5"))  # Результат: 10
```

## 4 Error Handling

### 4.1 Ошибка значения 
#### 4.1.1 `ValueError`: Возникает в большинстве случаев некорректного ввода:
- Пустая строка: `int("")`.
- Наличие букв: `int("12a")`.
- Число с точкой в строке: `int("10.0")`.
- Пробелы между цифрами: `int("10 00")`.
#### 4.1.2 Ошибка типа `TypeError`: Возникает, если в функцию передан объект, который в принципе нельзя преобразовать (например, список или словарь): 
- `int([1, 2])`

#### 4.2 Шаблон безопасного преобразования:

```python
raw_data = input("Введите целое число: ").strip()
try:
    clean_number = int(raw_data)
except ValueError:
    print(f"Ошибка: '{raw_data}' не является целым числом.")
```

# Степень

## 1 Core Concepts

- Определене: Степень (возведение в степень) — операция умножения числа само на себя заданное количество раз.  

### 1.1 Записывается как: `a^b`, где:

  - `a` — основание
  - `b` — показатель степени

### 1.2 В Python поддерживаются:

  - Положительные степени
  - Отрицательные степени (обратное значение)
  - Дробные степени (извлечение корня)

## 2 Syntax

### 2.1 Оператор степени:

```python
result = a ** b
```

### 2.2 Использование встроенной функции `pow(base, exp, mod=None)`:

```python
# Базовое использование
print(pow(2, 3))     # 8
```

```python
# Возведение в степень по модулю (быстрее, чем (a ** b) % mod)
print(pow(2, 3, 3))  # 2 (Так как 8 % 3 = 2)
```

### 2.3 Использование отрицательной степени

```python
print(2 ** -1)     # 0.5
```


### 2.4 Комплексные числа при дробной степени
В стандартной математике Python извлечение корня из отрицательного числа через оператор - может привести к созданию объекта типа complex. 
Однако для полноценной работы и избежания путаницы рекомендуется использовать специализированный модуль.

```python
print((-1) ** 0.5)  # выведет (6.123233995736766e-17+1j)
```

#### 2.4.1 Использование cmath: Модуль cmath (complex math) предназначен специально для вычислений с комплексными числами.

```python
import cmath

# Извлечение корня из отрицательного числа
result = cmath.sqrt(-1)
print(result)  # 1j (мнимая единица)
```

### 2.5 Переполнение и работа с большими числами
Python уникален тем, что его тип `int` обладает произвольной точностью (ограничен только вашей оперативной памятью), но это имеет свои последствия.
Чем больше число, тем медленнее выполняются операции с ним. Экстремально большие степени могут привести к «зависанию» программы или потреблению всей доступной памяти (Memory Error).

### 2.6 Числа с плавающей точкой (float) при работе со степенью
Если результат возведения в степень слишком велик для типа float, возникнет OverflowError. Подробнее см. раздел «Числа с плавающей точкой».

## 3 Best Practices

Использовать ** для читаемости кода:
```
x = 5 ** 2
print(x) # 25
```

Применять `pow()` с тремя аргументами для эффективных вычислений по модулю (например, в криптографии).
Избегать лишних вычислений — сохранять результат в переменную, если используется повторно.
Для больших чисел учитывать производительность и память.

## 4 Error Handling

### 4.1 Ошибка типа:

```python
print("2" ** 3)  # TypeError
```

### 4.1.1 Решение: привести тип строки в число

```python
print(int("2") ** 3) # Выведет 8
```

### 4.2 Деление на ноль при отрицательной степени:

````python
print(0 ** -1)  # ZeroDivisionError
````

# Числа с плавающей точкой

## 1 Core Concepts
Определение: Тип данных float используется для представления вещественных чисел (чисел с дробной частью).
Стандарт: В Python float соответствует 64-битному формату IEEE 754. Это означает, что под число выделено фиксированное количество памяти.
Разделитель: В качестве разделителя всегда используется точка.

## 2 Syntax

### 2.1 Способы записи

```Python
# Стандартная запись
price = 19.99
```
```python
# Экспоненциальная запись (для очень больших или малых чисел)
distance = 1.5e8  # 1.5 * 10^8 (150 000 000.0)
micro = 1e-4      # 1 * 10^-4 (0.0001)
```

### 2.2 Приведение типов

```Python
x = float(10)    # 10.0
y = float("5.5") # 5.5
```

## 3 Особенности и ограничения (Важно!)

### 3.1 Проблема точности (Precision Error)

Из-за того, что компьютеры хранят дробные числа в двоичном виде, некоторые десятичные дроби нельзя представить абсолютно точно.

```Python
print(0.1 + 0.2)  # 0.30000000000000004
```

Совет: Никогда не сравнивайте float через строгое равенство ==. Вместо этого проверяйте близость значений через `1.8e308` или используйте `math.isclose()`.

### 3.2 Специальные значения

Тип float поддерживает три уникальных состояния, которых нет у int:
- inf (Infinity): Положительная бесконечность.
- -inf: Отрицательная бесконечность.
- NaN (Not a Number): Результат математически неопределенных операций.

```Python
import math

print(math.inf > 10**100) # True
print(float('nan'))       # nan
```

## 4 Error Handling

### 4.1 OverflowError (Переполнение).

В отличие от целых чисел `int`, которые могут расти до размеров всей оперативной памяти, тип float имеет жесткий верхний предел (примерно $1.8 \times 10^{308}$).

```Python
try:
    result = 2.0 ** 1024  # Слишком много для float
except OverflowError:
    print("Ошибка: Число слишком велико (float overflow)")
```

### 4.2 ValueError

Возникает при попытке преобразовать строку, не являющуюся числом.

```Python
float("12.5a")  # ValueError: could not convert string to float
```

### 5. Best Practices

Финансовые расчеты: Для работы с деньгами, где важна абсолютная точность до копейки, используйте модуль decimal вместо float.

# Считывание данных с экрана

## 1 Core Concepts
Трансформация потока: Получение данных через `input()` всегда возвращает строку (str). Для выполнения арифметических операций требуется явное приведение к типу `int`.
Блокировка выполнения: Программа приостанавливается до тех пор, пока пользователь не нажмет клавишу Enter.
Цепочка вызовов: Стандартный паттерн в Python — вложение `input()` непосредственно в `int()`, что позволяет избежать создания лишних промежуточных переменных.

## 2 Syntax

### 2.1 Функция ввода. 
Она приостанавливает выполнение программы, выводит текст в консоль и ждет, пока пользователь что-то введет и нажмет Enter. 
Важно: она всегда возвращает данные в виде строки (str), даже если пользователь ввел цифры. `int(input("Подсказка"))`

```python
age = int(input("Введите ваш возраст: "))
# Считывание нескольких чисел в одну строку
```

#### 2.2 Массовый ввод и преобразование в список

Это классический «однострочник», который заменяет собой целый цикл for.

```python
numbers = list(map(int, input("Введите числа через пробел: ").split()))
print(f"Список координат: {coords}") 
# Если ввели '100 200 50', получим [100, 200, 50]
```

#### 2.3 Распаковка в переменные

```python
a, b = map(int, input("Введите два числа: ").split())
```

## 3 Best Practices

### 3.1 Защита от пробелов
Всегда добавляйте `.strip()` к `input()`. Это предотвратит ошибку, если пользователь случайно введет пробел перед или после числа.

```python
value = int(input("Введите ID: ").strip())
```

### 3.2 Информативность
Строка-подсказка должна быть лаконичной и указывать на ожидаемый формат (например, «Введите целое число»).
Разделение ввода и логики: В сложных скриптах лучше сначала получить строку, проверить её, а затем приводить к типу.

## 4 Error Handling

### 4.1 ValueError: Основная ошибка. 
Возникает при вводе букв, пустой строки или чисел с плавающей точкой (10.5).
Паттерн «Бесконечный цикл»: Самый надежный способ гарантировать получение корректного числа.

```python
while True:
    user_input = input("Введите целое число: ").strip()
    try:
        result = int(user_input)
        break  # Ввод корректен, выходим из цикла
    except ValueError:
        print(f"Ошибка! '{user_input}' не является целым числом. Попробуйте еще раз.")
```

### 4.2 Массовый ввод и преобразование в список

Эта конструкция очень чувствительна к ошибкам ввода. Она вызовет ValueError, если:
- Пользователь введет букву вместо числа (например, 10 20 а).
- Вместо чисел будет введена пустая строка.
- Рекомендация для методички:

При использовании этой конструкции всегда оборачивайте её в блок try-except ValueError, чтобы программа не закрывалась при случайной опечатке пользователя.


# Преобразование целого числа в строку

## 1 Core Concepts
Смена представления: Преобразование `int` в `str` изменяет способ хранения данных в памяти. Вместо двоичного числа для вычислений Python создает последовательность символов (текст), пригодную для вывода и форматирования.
Неявное vs Явное: В отличие от некоторых языков, Python не преобразует числа в строки автоматически при сложении (конкатенации). Для объединения текста и числа всегда требуется явное приведение типов или использование инструментов форматирования.
Индексация: После преобразования в строку число становится итерируемым объектом — к каждой его цифре можно обратиться по индексу, как к элементу списка.

```python
argum_line = '1234'
print(argum_line[0])
# выведет: '1' (это все еще строка)
```
## 2 Syntax

Базовая функция str()

### 2.1 Синтаксис: str(числовое_значение)

```python
age = 25
age_str = str(age)
print("Мне " + age_str + " лет")
```

Современное форматирование (f-strings)
Этот метод автоматически вызывает `str()` под капотом и является предпочтительным.

### 2.2 Синтаксис: f"{переменная}"

```python
count = 100
message = f"Найдено объектов: {count}"
```

Старый стиль (иногда встречается в легаси-коде)

```python
result = "Ответ: {}".format(42)
```

## 3 Best Practices

Приоритет f-строк: Всегда используйте f"{var}" вместо str(var) для вывода и формирования сообщений. Это производительнее и чище.
Форматирование чисел (Leading Zeros): Если вам нужно дополнить число нулями (например, для нумерации файлов 001, 002), используйте спецификаторы формата:

```python
num = 5
formatted = f"{num:03}"  # Результат: "005"
```

### 3.1 Обработка цифр
Используйте str() только в том случае, если вам действительно нужно работать с числом как с текстом (например, проверить длину числа через `len(str(num))` или перевернуть его).

### 3.2 Задача - Сумма цифр

Если мы хотим сложить цифры, нам нужно превратить символ обратно в число.

```python
argum_line = '1234'
# Складываем первое и второе "число", преобразовав их из строки
sum_digits = int(argum_line[0]) + int(argum_line[1])
print(sum_digits) # Выведет: 3
```

## 4 Error Handling
Безопасность преобразования: Функция `str()`практически «неубиваема». В отличие от `int()`, она успешно преобразует любой объект Python (списки, словари, числа) в строковое представление.
Лимит на количество цифр: В современных версиях Python (начиная с 3.10.7) введено ограничение на преобразование очень больших чисел в строки (по умолчанию 4300 знаков) для защиты от DoS-атак.

```python
# При попытке преобразовать число из 100 000 цифр
import sys
sys.set_int_max_str_digits(100000)  # Чтобы избежать ValueError: Exceeds the limit
```

### 4.1 Ошибка атрибута `AttributeError`

Если вы случайно попытаетесь вызвать метод `str()` как метод объекта (например, `x.str()`), возникнет ошибка. `str()` — это встроенная функция-конструктор, а не метод переменной.

# Присвоение значению переменной целой математической формулы

## 1 Core Concepts

Приоритет вычисления: В Python выражение справа от оператора присваивания `=` всегда вычисляется первым. Только после того, как получен финальный результат, он записывается в переменную.
Выражение (Expression): Это комбинация значений, переменных и операторов, которая после вычисления сводится к одному значению.
Порядок операций (PEMDAS/BODMAS): Python следует стандартным математическим правилам: сначала скобки, затем возведение в степень, потом умножение/деление, и в конце — сложение/вычитание.

## 2 Syntax

### 2.1 Сложение (+) и Вычитание (-)

```python
result = 10 + 5 - 2  # 13
```

### 2.2 Умножение (*) и Возведение в степень (**)

```python
square = 5 ** 2      # 25
area = 3.14 * (10 ** 2)
```

### 2.3 Деление (всегда возвращает float)

```python
div = 10 / 2         # 5.0
```

### 2.4 Целочисленное деление (//) и Остаток от деления (%)

```python
floor_div = 10 // 3  # 3 (отсекает дробную часть)
remainder = 10 % 3   # 1 (остаток)
```

### 2.5 Использование переменных в формулах

```python
price = 100
tax_rate = 0.2
# Формула с использованием ранее объявленных переменных
total_price = price + (price * tax_rate)
```

### 2.6 Группировка скобками

```python
# Без скобок: 2 + 15 = 17
# Со скобками: 5 * 5 = 25
value = (2 + 3) * 5 
```

## 3 Best Practices
PEP 8 (Пробелы): Окружайте операторы присваивания и арифметические операторы одиночными пробелами для читаемости: x = a + b (а не x=a+b).
Разбиение сложных формул: Если формула занимает более 80 символов, разбейте её на промежуточные переменные. Это упрощает отладку и чтение кода.

```python
# Плохо
total = (count * price) + (count * price * tax) - discount + shipping_fee
```

```python
# Хорошо
subtotal = count * price
tax_amount = subtotal * tax
total = subtotal + tax_amount - discount + shipping_fee
```

Использование констант: Числа с фиксированным смыслом (например, число Пи или гравитационная постоянная) выносите в переменные с именами в ВЕРХНЕМ_РЕГИСТРЕ.

## 4 Error Handling

### 4.1 Деление на ноль 

(ZeroDivisionError): Самая частая ошибка в формулах. Если переменная в знаменателе может оказаться нулем, код «упадет».

```python
try:
    result = total / count
except ZeroDivisionError:
    result = 0
```
### 4.2 Ошибка типа (TypeError): 

Возникает при попытке применить математику к несовместимым типам (например, число + строка). Нужно использовать `int()` или `float()`.

```python
x = 10 + input("Число: ") 
```

### 4.3 Переполнение (OverflowError)

В Python целые числа `int` имеют произвольную точность и ограничены только вашей оперативной памятью. Однако числа с плавающей точкой `float` имеют предел, при превышении которого возникнет ошибка или значение `inf` (бесконечность).

# Вычитание(минус)

## 1 Core Concepts

Бинарный оператор: Оператор вычитания `-` работает с двумя операндами: из первого (уменьшаемого) вычитается второе (вычитаемое), результатом является их разность.
Унарный минус: Тот же символ используется для смены знака числа на противоположный (например, из 5 делает -5).
Типизация результата:
`int` - `int` всегда дает `int`.
`float` - `float` или `int` - `float` всегда дает `float`.

## 2 Syntax

### 2.1 разность = уменьшаемое - вычитаемое

```python
diff = 10 - 3  # Результат: 7
```

### 2.2 Использование с переменными

```python
balance = 1000
price = 250
new_balance = balance - price
```

### 2.3 Сокращенное присваивание (Augmented Assignment)
Используется для уменьшения значения переменной на определенное число.

```python
health = health - 10
```

Эквивалентно:

```python
health = 100
health -= 10  # Результат: 90
```

### 2.4 Унарный минус

```python
x = 10
y = -x  # Результат: -10
```

## 3 Best Practices

### 3.1 Пробелы по PEP 8

Всегда окружайте оператор `-` пробелами: a - b. Исключение — унарный минус: -5 (пишется слитно с числом).

### 3.2 Имена переменных 

Используйте говорящие названия для уменьшаемого и вычитаемого, чтобы логика формулы была понятна без комментариев: `total_amount - discount`.

### 3.3 Декрементирование

Для уменьшения счетчика на единицу используйте count -= 1, это стандартный и наиболее читаемый способ в Python.

## 4 Error Handling

### 4.1 Ошибка типа (TypeError)

Возникает при попытке вычесть что-либо из строки или наоборот.

```python
# Ошибка: TypeError: unsupported operand type(s) for -: 'int' and 'str'
result = 10 - "5" 
```

### 4.2 Точность чисел с плавающей точкой (Floating Point Precision)

Из-за особенностей хранения float в памяти, результат вычитания может быть неожиданным.

```python
print(0.3 - 0.2)  # Выведет: 0.09999999999999998 (а не 0.1)
```

### 4.3 Решение для точных расчетов:

```python
from decimal import Decimal
print(Decimal('0.3') - Decimal('0.2'))  # Выведет: 0.1
```

### 4.4 Отсутствие переменной (NameError)
Если одна из переменных в формуле не была объявлена ранее.

```python
result = price - discount # Ошибка, если price или discount не определены
```
