# Swiss-Type Machining Calculator

Специализированный калькулятор для расчета времени цикла на автоматах продольного точения (Swiss-type CNC). 

## 🚀 Основные возможности
- **Двухканальный расчет**: Одновременная работа с основным шпинделем (Main Spindle) и противошпинделем (Back Spindle).
- **Поддержка 7 типов операций**: Facing, Turning, Milling, Drilling (G1), Drilling (Q), Whirling, Threading.
- **Конфигурация станков**: Гибкая настройка параметров станка (ускорения, время смены инструмента) через JSON.
- **Экспорт отчетов**: Генерация детального `.txt` отчета с результатами расчетов.

## 🛠 Математический фундамент

Программа использует стандартные производственные формулы, дополненные коэффициентами для учета холостых ходов и специфики кинематики автоматов продольного точения.

### Общие формулы времени (T)
*   **Точение / Сверление (G1):** `T = L / (S * F) + (1.3 * L) / Rapid_Traverse`
    *   *Коэффициент 1.3* учитывает подвод, отвод и безопасные зазоры.
*   **Фрезерование / Whirling:** `T = L / F_min + (1.2 * L) / Rapid_Traverse`
    *   *Коэффициент 1.2* учитывает специфику линейных перемещений фрезы.

### Специфические расчеты
*   **Drilling (Q) - Глубокое сверление:** 
    Учитывает количество "пиков" (pecks) и время на каждый возврат инструмента для очистки стружки.
    `T_rapid = (Peck_Depth * N_pecks * (N_pecks + 1)) / Rapid_Traverse`
*   **Threading - Резьбонарезание:**
    Рассчитывается как сумма времени каждого прохода (Length * Passes).
*   **Turning - Многопроходное точение:**
    Автоматически рассчитывает количество проходов на основе общей глубины съема и глубины за один проход.

## ⚙️ Настройка станков (`machines_config.json`)

Вы можете редактировать или добавлять свои станки в файл `machines_config.json`. 

Пример структуры:
```json
"Citizen_20": {
    "description": "Swiss-type automatic lathe Citizen 20mm",
    "rapid_traverse_mm_min": 20000,
    "tool_change_time_s": 1.5,
    "cutoff_time_s": 5.0,
    "re_grip_time_s": 3.5,
    "ejection_time_s": 2.0
}
```
*   `rapid_traverse_mm_min`: Скорость быстрых перемещений (G0) в мм/мин.
*   `tool_change_time_s`: Среднее время смены инструмента в секундах.
*   `cutoff_time_s`: Время на операцию отрезки.

## 💻 Технологический стек
- **Python 3.10+**
- **CustomTkinter**: Современный UI интерфейс.
- **OOP Architecture**: Четкое разделение бизнес-логики (Core), интерфейса (GUI) и утилит (Utils).

## 📋 Установка и запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   python main.py
   ```
