├── gui/                   # Графический интерфейс
│   ├── __init__.py
│   ├── app.py             # Главное окно и навигация (Двухпанельный режим)
│   ├── main_spindle.py    # UI вкладки основного шпинделя
│   └── back_spindle.py    # UI вкладки противошпинделя

│   ├── __init__.py
│   ├── config_loader.py   # Безопасная загрузка JSON-конфигураций
│   └── file_exporter.py   # Генерация .txt отчетов

## 🧪 Математический фундамент (В процессе обсуждения)

### Общие формулы:
- [x] **Время точения/сверления (T):** `T = L / (S * F) + (1.3 * L) / Rapid_Traverse`
- [x] **Время фрезерования (T):** `T = L / F_min + (1.2 * L) / Rapid_Traverse`
